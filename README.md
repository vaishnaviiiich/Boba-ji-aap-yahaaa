# Gengar.exe

An interactive, scroll-animated webpage exploring the less comfortable corners of Pokemon lore, hosted by a ghost who refuses to leave the laptop.

## What is this

This is a personal web project built with vanilla HTML, CSS, and JavaScript. There are no frameworks, no twenty-megabyte node_modules folders, and no build steps that fail because of a minor version mismatch on a Monday morning.

The site is themed around Gengar and ghost-type Pokemon folklore, mixed with a light layer of self-aware student and developer humor.

## Included sections

- The Uninvited Roommate: A hero section featuring a CSS-drawn Gengar that bobs slightly and observes your screen.
- Internal Workspace: A small mock desktop containing four lightweight apps:
  - Pokedex Notes: Actual field descriptions of Pokemon that make you question the age rating of the games.
  - Mock Terminal: A command line that responds to a handful of basic prompts.
  - Daily Regrets: Relatable developer notes about broken loops and cold coffee.
  - Bug Chaser: A tiny canvas game where you chase red squares with your keyboard arrows.
- Uncomfortable Truths: Cards explaining the Clefable shadow theory, trade evolution mechanics, and why Lavender Town was an odd choice for a children's title.
- Historical Footnotes: A minimal timeline summarizing ancient Pokemon catastrophes and why researchers should stop cloning things in island basements.

## File structure

- index.html: Semantic markup, no framework dependencies.
- style.css: Hand-written stylesheet with custom properties, smooth scroll animations, and a dark purple palette.
- script.js: Vanilla logic handling scroll progress, modal windows, audio cues, and the mini game.

## How to run it

Double-click index.html or open it in any modern web browser. It does not need a local server, an internet connection, or an installation wizard.
